# FEATURES

- Alarm (Core feature)

- Dynamic Schedule

- Deactivation Code (QR Code, NFC Tag, ...)

---
# USE CASES

## Alarm (core feature)

- Create alarm

- Manage alarms

- Edit alarm

- Disable alarm

- Remove alarm

  

## Dynamic Schedule

- Select Calendar for interconnection

- GrantCalendarPermissions

- Preview of the Calendar to Sync with

- (Algorithm to calculate alarm time based on sleep goal, duration to wake up and duration to get ready)

  

## Sleep Habits Configuration

- Sleep Goal
- Duration to wake up
- Duration to get ready (between getting up and setting off)
- Reminder Feature (Reminders for bedtime to encourage a regular sleep schedule)
- Gentle Wake Feature
- Do Not Disturb Feature
  - Turn off notifications
  - Turn off calls



## Deactivation Code

- Create Deactivation Code
- Manage Deactivation Codes
- Disable Deactivation Code
- Remove Deactivation Codes
- Print Deactivation Code as QR Code (="QR Code")
- Scan QR Code
- Optional: Write Deactivation Code to NFC Tag (="Deactivation Tag")
- Optional: Read Deactivation Tag
